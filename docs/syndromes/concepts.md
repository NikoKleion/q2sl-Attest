# Concepts

- **Stabilizer code.** The joint +1 eigenspace of an abelian subgroup S of the n-qubit Pauli group with
  -I not in S; an [[n, k, d]] code has n - k independent generators (Gottesman, arXiv:quant-ph/9705052).
  `codes.STANDARD` holds the built-in codes.
- **Syndrome.** The outcomes of the n - k generator measurements, one of 2^(n-k) strings. For an input
  state rho and a channel E, P(s | rho) = Tr(Pi_s E(rho)), with Pi_s the projector onto syndrome s.
- **Total variation distance.** Half the L1 distance between two distributions. `population_leak` is the
  total variation distance between P(s | |0_L>) and P(s | |1_L>). `phase_leak` is the largest entrywise
  difference between P(s | |+_L>) and the distribution for other equatorial logical states. The `pauli`
  value in each report is the population measure under a depolarizing channel. A Pauli channel gives the
  same syndrome distribution for every logical state (Wagner, Kampermann, Bruss and Kliesch 2022, eq. 40),
  so it reads zero.
- **More than one logical qubit.** A code with k > 1 builds its logical operators as k pairs with
  <Z_i, X_j> = delta_ij, by Gram-Schmidt over GF(2). `code.k` is the count, `code.logical_pairs` holds the
  strings and `code.with_logical(i)` returns the same code with logical qubit i as the one every measure
  reads, so the leak, the order, the distance and the recovery are reported one logical qubit at a time.
  The state that carries them fixes every other logical qubit at Z_i = +1. These numbers belong to the
  basis the construction picks: on the L=2 toric code, combining the two pairs moves the second reading
  from 5.58e-02 to 9.08e-02 on the same code and the same channel.
- **Logical basis.** `css_from_matrices` and `css_strings` take Z_L as a Z-type string in ker(Hx) and X_L
  as an X-type string in ker(Hz), so |0_L> and |1_L> are the eigenstates of a Z-type operator. Amplitude
  damping drives population from |1> to |0> on each physical qubit, so it separates logical states along
  that axis and no other: the conjugate pair |+_L> and |-_L> gives a distance of 0 on every code here, and
  `worst_pair` finds the |0_L>, |1_L> axis to be the most distinguishable pair over a grid of 58 states.
  Published labellings of a code need not agree with this one. For the Shor code Z_L is ZIIZIIZII, while
  the textbook labelling takes the X-type XXXXXXXXX as its logical Z, so the textbook |0_L> is |+_L> here
  and its two basis states carry no population leak. `hardware.build_shor_circuits` prepares the states of
  this convention, which is why it feeds |+> and |-> into the encoder.
- **Wasserstein-1 distance.** `wasserstein.w1_leakage` is the Wasserstein-1 distance between the two
  syndrome distributions with the Hamming distance between syndrome strings as the ground metric. It
  reports a lower bound when the exact transport problem is too large.
- **Analytic order.** `analytic_leak` returns the smallest weight |A| such that Z_A lies in the group
  generated by S and Z_L, A lies inside the Z-support of some element of S, and A overlaps the support of
  X_L in an odd number of qubits. `measured_order` fits the slope of the exact total variation distance
  against gamma, and [results.md](../results.md) lists both for each code. For the [[4,1,2]] code, Leung, Nielsen, Chuang
  and Yamamoto (1997) find the detection probabilities vary across the codespace at order gamma^2.
- **Attack and bounds.** For r independent syndrome shots the likelihood-ratio test is the optimal test
  between two known distributions (Neyman and Pearson, 1933); `ml_attack` simulates it. Its error decays
  as exp(-C r) with the Chernoff information C = -log min over s in [0, 1] of sum_x p(x)^s q(x)^(1-s)
  (Cover and Thomas, Elements of Information Theory, section 11.9); `chernoff_exponent` minimises over a
  201-point grid in s. `eavesdropper_error` is the Bhattacharyya bound (1/2)(sum_x sqrt(p(x) q(x)))^r,
  the s = 1/2 term. `rounds_for_error(target)` is ceil(log(1 / target) / C).
- **Readout error.** `expectations.syndrome_dist(..., readout=q)` and `population_leak(..., readout=q)`
  flip each syndrome bit with probability q, which may be one rate or one per generator.
  `expectations.apply_readout(d, q)` does the same to a distribution. A flip on bit j multiplies the
  expectation of every group element containing generator j by 1 - 2q, so the cost is one multiplication.
  Every other measure in the package assumes the generators are measured without error.
- **One channel per qubit.** Every function that takes a Kraus list also takes a list of n of them, one
  per qubit, built by `channels.per_qubit_damping(gammas)` or `channels.per_qubit_t1t2(t1s, t2s, time)`.
  A list of identical channels reproduces the single-channel path exactly. The `disorder` run measures what
  the spread of a device's T1 does to the leak.
- **Channels.** Amplitude damping with parameter gamma and the T1, T2 relaxation channel of
  `channel_from_t1t2`, in Kraus form after Nielsen and Chuang, section 8.3. `coherent_diagonal(theta)` is
  the unitary diag(1, exp(i theta)) on every qubit. `generalized_amplitude_damping(gamma, p)` relaxes toward
  |0> with weight p and toward |1> with weight 1 - p; at the default p = 0.5 it is a Pauli channel and gives
  no leak.
